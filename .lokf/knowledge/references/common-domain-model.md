# Common Domain Model (lmodel)

The `object_source` of the [gist to CDM mappings](../datasets/gist-cdm-mappings.md), whose metadata describes it as "FINOS CDM classes" and binds the prefix `common_domain_model:` to `https://w3id.org/lmodel/common-domain-model/`, the namespace the schemas of `lmodel/common-domain-model` declare. The w3id identifier redirects to `https://lmodel.github.io/common-domain-model`. This repository holds no copy of it; the mappings name its classes by CURIE only, and `just verify-mapping-targets` fetches its schema folder at a pinned commit to check that every mapped class exists.
