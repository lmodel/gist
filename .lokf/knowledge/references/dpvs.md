# DPV (lmodel)

The `object_source` of the [gist to DPV mappings](../datasets/gist-dpvs-mappings.md), which bind the prefix `dpv:` to `https://w3id.org/lmodel/dpv/`, the namespace the schemas of `lmodel/dpv` declare. The repository was formerly named `lmodel/dpvs`. The w3id identifier redirects to `https://lmodel.github.io/dpv`. This repository holds no copy of it; `just verify-mapping-targets` fetches its schema folder at a pinned commit to check that every mapped term exists.
