# Datasets

* [gist 14.1.0 upstream Turtle release](gist-upstream-turtle.md) - the five Semantic Arts Turtle modules the build starts from.
* [gist LinkML schema](gist-linkml-schema.md) - the six generated LinkML modules under `src/gist/schema/`.
* [gist to Common Domain Model mappings](gist-cdm-mappings.md) - 35 manually curated SSSOM rows.
* [gist to DPVs mappings](gist-dpvs-mappings.md) - 12 LLM-matched SSSOM rows.
* [gist to ISO/IEC 22989 mappings](gist-iso22989-mappings.md) - 9 LLM-matched SSSOM rows.
* [gist generated schema artefacts](generated-artefacts.md) - OWL, SHACL, JSON Schema and the other LinkML generator outputs.
* [gist example and test data](test-data.md) - valid, invalid and known-problem instances.
* [Semantic Arts gist SHACL shapes (vendored)](semantic-arts-shapes.md) - shapes and a CONSTRUCT query used by the SHACL tests.
